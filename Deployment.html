Deploying a Streamlit App to Community Cloud

A step-by-step guide to hosting your Python application on GitHub and deploying it for free on Streamlit Community Cloud.

1 Prepare Your Repository Files

Ensure your local project directory contains all the required files before pushing to GitHub:

  • app.py: Your main Streamlit script containing your application code.
  • requirements.txt: The Python packages required by your application.
  • packages.txt (Optional): System-level packages (like ffmpeg or C libraries) required by Python audio/video libraries.

Example requirements.txt

streamlit
google-genai
edge-tts
streamlit-mic-recorder

2 Push Project to GitHub

Publish your application code to a public or private GitHub repository:

  1. Go to GitHub and create a new repository (e.g., ai-teacher-streamlit).
  2. In your local terminal, initialize Git, commit your files, and push to GitHub:
git init
git add app.py requirements.txt
git commit -m "Initial commit for Streamlit app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main

3 Deploy on Streamlit Community Cloud

Connect your GitHub repository to Streamlit's hosting platform:

  1. Visit share.streamlit.io and sign in with your GitHub account.
  2. Click "Create app" or "New app".
  3. Select "I already have an app" and fill in the details:
    • Repository: Select your GitHub repository (e.g., YOUR_USERNAME/YOUR_REPOSITORY).
    • Branch: main
    • Main file path: app.py

4 Configure Environment Secrets

If your application requires API keys (such as GEMINI_API_KEY), set them securely in Streamlit Cloud rather than hardcoding them into your repository.

  1. On the deployment setup screen (or under App Settings > Secrets), expand Advanced settings.
  2. Add your secrets using TOML format:
GEMINI_API_KEY = "your_actual_gemini_api_key_here"
Security Reminder: Never upload plain-text API keys or credentials directly to public GitHub repositories. Always use st.secrets for cloud deployment.

5 Launch and Manage

  1. Click "Deploy!"
  2. Streamlit Cloud will install the dependencies specified in requirements.txt and build your application container.
  3. Once complete, your app will be live at a public URL (e.g., https://your-app-name.streamlit.app).
  4. Any future updates pushed to your main branch on GitHub will automatically trigger a redeployment on Streamlit Cloud.
